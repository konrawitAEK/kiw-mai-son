## 1. โปรเจกต์นี้คืออะไร

**ระบบจองคิวผ่าน LINE OA ของร้าน** สำหรับร้านทำผม ทำเล็บ ต่อขนตา และบาร์เบอร์ขนาดเล็ก (ช่าง 1–4 คน) ที่ยังรับจองผ่านแชท LINE ส่วนตัวหรือสมุด และเจอปัญหา **คิวซ้อน** และ **ลูกค้าเบี้ยวนัด**

| | |
|---|---|
| ปัญหาที่แก้ | ตอบแชทจองทั้งวันระหว่างทำงาน · ลงคิวซ้อนจนเสียลูกค้า · ลูกค้าไม่มาตามนัด เก้าอี้ว่าง |
| ลูกค้าเป้าหมายแรก | ร้านทำเล็บ/ต่อขนตา และร้านทำผม ที่เบี้ยวนัด/คิวซ้อน **หลายครั้งต่อเดือน** (เจาะแคบ ไม่ใช่ทุกร้าน) |
| ราคา | ฟรี 30 วัน → 199 บาท/เดือน หรือ 1,990 บาท/ปี · 30 ร้านแรกฟรี 3 เดือนแลกรีวิวจริง |
| ต่างจากแอปจองคิวฟรี | ใช้ใน LINE ที่ลูกค้าใช้อยู่แล้ว ไม่ต้องโหลดแอป · เจ้าของลงคิวแทนลูกค้าที่โทรมาได้ · มัดจำพร้อมเพย์เข้าบัญชีร้านตรง · ติดตั้งให้ |

**อ่านผลอย่างไร**
- ตัวเลขซื้อของลูกค้าจำลองคือ "เพดาน" ไม่ใช่การพยากรณ์ Haiku เข้มกว่าโมเดลหลักชัดเจน (8 → 5 ด้วยข้อเสนอเดียวกัน) ให้ถือว่าความจริงน่าจะอยู่ระหว่างสองค่านี้หรือต่ำกว่า
- **ข้อคัดค้านอันดับ 1 = ความไว้ใจ**: ไม่รู้จักคนทำ, ไม่อยากให้คนนอกเป็นแอดมิน LINE OA, ระบบพังกลางวันใครแก้, ฝากทั้งร้านไว้กับนักพัฒนาคนเดียว
- ข้อคัดค้านรอง: ลูกค้าประจำอายุเยอะ/ชินทักแชทส่วนตัว, ค่ารายเดือน
- ราคา: ช่วงที่รับได้ ~50–300 บาท/เดือน (Haiku) ถึง ~50–390 (main) · 199 อยู่ในช่วง · "เริ่มแพง" ที่ ~250–300
- คำว่า "ซื้อ" หลายคนหมายถึง "ลองฟรี 30 วันแล้วจ่ายถ้าเห็นผล" — ตัวเลขที่ต้องวัดจริงคือ **อัตราจ่ายต่อหลังหมดช่วงฟรี**

**สิ่งที่ต้องเปลี่ยนในข้อเสนอจริง (จากผล Haiku)**
1. **ไม่ต้องให้เราเป็นแอดมิน OA**: เจ้าของร้านกดเองระหว่างวิดีโอคอล เราแค่บอกทาง → ระบบได้ token ที่ร้านถอนได้เองทุกเมื่อ
2. **หน้าเพจ "ใครทำ"**: ชื่อจริง หน้า วิดีโอแนะนำตัว เลขที่ติดต่อ (สร้างความไว้ใจที่ Haiku ถามหา)
3. **สัญญาที่ทำได้จริง**: ผู้ก่อตั้งทำงานประจำกลางวัน → ห้ามสัญญา "ตอบใน 30 นาที" ใช้ "ตอบภายในวันเดียวกัน + ระบบสำรอง: ถ้าระบบล่ม ลูกค้ายังทักจองในแชทร้านได้ และเจ้าของเห็นตารางล่าสุดเสมอ" แล้วลงแรงที่ความเสถียรแทนความเร็วในการตอบ
4. **รีวิวจากร้านจริง** คือสิ่งที่พลิก "ไม่ซื้อ" ได้มากที่สุด → แผนทั้งหมดด้านล่างเริ่มจากการได้ร้านนำร่องจริง

## 3. กระบวนการทำงานของระบบ (Flow)

### 3.1 ฝั่งลูกค้าของร้าน
1. ลูกค้าเปิด LINE OA ของร้าน → กดเมนู "จองคิว" (Rich menu)
2. หน้า LIFF เปิดในแอป LINE: เลือกบริการ → เลือกช่าง (หรือ "ช่างคนไหนก็ได้") → เห็นเฉพาะช่วงเวลาว่าง
3. ยืนยัน → (ถ้าร้านเปิดมัดจำ) แสดง QR พร้อมเพย์ของร้านพร้อมยอด → ลูกค้าโอน + แนบสลิป
4. ได้ข้อความยืนยันใน LINE (reply message)
5. ก่อนนัด 1 วัน ได้ข้อความเตือน + ปุ่ม "ยืนยันมา" / "ขอเลื่อน"

### 3.2 ฝั่งเจ้าของร้าน (หน้า Admin ใน LIFF)
- ตารางวันนี้/สัปดาห์นี้ แยกตามช่าง
- **ลงคิวแทน** ลูกค้าที่โทร/ทักส่วนตัว (ชื่อ + เบอร์ + บริการ + เวลา) ปุ่มเดียว
- ปิดช่วงเวลา (ช่างลา/พัก), ตั้งเวลาเปิด-ปิด, บริการ+ระยะเวลา+ราคา+ยอดมัดจำ
- ตรวจสลิปมัดจำ → กดยืนยัน
- ดูสถิติ: จำนวนจอง, เบี้ยวนัด, รายได้จากมัดจำ

### 3.3 ฝั่งผู้ก่อตั้ง (Operation)
1. ร้านสมัคร (LINE OA ของเรา / ฟอร์ม) → นัดวิดีโอคอล 30 นาที
2. ระหว่างคอล: ร้านสร้าง Messaging API channel ใน OA ของตัวเอง → วาง token ในหน้า setup ของเรา → ตั้งบริการ/ช่าง/เวลา → ตั้ง Rich menu อัตโนมัติ → ทดลองจองจริง 1 ครั้ง
3. ติดตามวันที่ 3, 7, 14, 28 ของช่วงทดลอง (ข้อความ LINE อัตโนมัติ + เช็กสถิติ)
4. วันที่ 25: ส่งสรุป "เดือนนี้ร้านคุณ: จอง X ครั้ง เบี้ยวลดจาก A เหลือ B" + ลิงก์จ่าย

## 4. แนวทางเทคนิค (เสนอ — ปรับตามที่ถนัด)

| ส่วน | แนะนำ | เหตุผล |
|---|---|---|
| หน้าเว็บใน LINE | LIFF + React (Vite) + TypeScript | เปิดในแอป LINE ได้ ได้ LINE user id ของลูกค้าทันที |
| Backend/API | Serverless (เช่น Cloudflare Workers หรือ Supabase Edge Functions) | ต้นทุนเริ่มต้น ~0, ไม่ต้องดูแลเซิร์ฟเวอร์ |
| ฐานข้อมูล | PostgreSQL (เช่น Supabase) | ใช้ **exclusion constraint บน tstzrange** กันคิวซ้อนที่ระดับฐานข้อมูล (กันซ้อนแม้กดพร้อมกัน) |
| ส่งเตือนนัด | Cron (pg_cron หรือ Workers Cron) → LINE push message | |
| มัดจำ | สร้าง QR พร้อมเพย์ตามมาตรฐาน EMVCo ด้วยเบอร์/เลขบัญชีพร้อมเพย์ของร้าน + ยอดเงิน, เงินเข้าร้านตรง เราไม่แตะเงิน | ไม่ต้องใช้ payment gateway ในเวอร์ชันแรก ตรวจสลิปด้วยมือโดยร้าน |
| หลายร้าน (multi-tenant) | 1 ร้าน = 1 LINE channel (token เข้ารหัสเก็บ) · webhook เดียว แยกร้านด้วย destination | |
| Monitoring | uptime check + แจ้งเตือนเข้า LINE ของผู้ก่อตั้ง | ความเสถียรคือจุดขายเรื่องความไว้ใจ |

> ⚠️ **ต้องเช็กก่อนเขียนโค้ด (สัปดาห์แรก):** เงื่อนไขและโควตาข้อความฟรีของ LINE OA ในไทยปัจจุบัน (ข้อความเตือนนัดเป็น push และนับโควตาของ **OA ร้าน**), ฟรีเทียร์ของบริการ hosting/DB ที่เลือก, ข้อกำหนด LIFF/Messaging API ล่าสุด — ตัวเลขในรายงานนี้ยังไม่ได้ตรวจกับแหล่งจริง

### โครงข้อมูลหลัก
`shops` · `line_channels` (token เข้ารหัส) · `staff` · `services` (นาที, ราคา, มัดจำ) · `working_hours` · `time_off` · `customers` (line_user_id, ชื่อ, เบอร์) · `bookings` (staff_id, ช่วงเวลา tstzrange, สถานะ, สถานะมัดจำ, ช่องทาง: line/แทนลูกค้า) · `reminders_log` · `subscriptions` (แผน, วันหมดทดลอง, วันจ่ายล่าสุด)

### กฎหมาย/ความเป็นส่วนตัว
- PDPA: ร้าน = ผู้ควบคุมข้อมูล, เรา = ผู้ประมวลผล → มีประกาศความเป็นส่วนตัว + ข้อตกลงประมวลผลข้อมูลกับร้าน, เก็บแค่ชื่อ/เบอร์/LINE id
- ภาษี: รายได้เข้าบุคคลธรรมดา ยื่นภาษีเงินได้ตามปกติ (ยังไม่ถึงเกณฑ์ VAT) — ถามนักบัญชีเมื่อรายได้เริ่มจริง
- **เช็กสัญญาจ้างงานประจำ** ว่าทำธุรกิจเสริม/ใช้เวลานอกงานได้ และไม่ใช้อุปกรณ์/โค้ดของบริษัท

## 8. การตลาด (ไม่ต้องโทรขาย)

### ช่องทางหลัก
1. **คลิปสั้น TikTok / Reels / FB** — 3 คลิป/สัปดาห์ ถ่ายรวดเดียววันเสาร์
   - "ลูกค้าเบี้ยวนัด 3 คน = เสียเท่าไร" (เปิดด้วยตัวเลขเงินที่ร้านเสีย)
   - สาธิตจอมือถือ: ลูกค้าจองเอง → เจ้าของได้แจ้งเตือน → ไม่มีคิวซ้อน (15–30 วิ)
   - "ร้านเล็บ (ชื่อจริง) หลังใช้ 1 เดือน" — เฉพาะเมื่อมีร้านจริงและได้รับอนุญาต
   - เบื้องหลังคนทำ (สร้างความไว้ใจ: ตอบข้อคัดค้านอันดับ 1)
2. **กลุ่ม Facebook ช่างทำเล็บ/ช่างทำผม/ต่อขนตา** — โพสต์ให้ความรู้ก่อนขาย: "ข้อความเก็บมัดจำที่ลูกค้าไม่โกรธ" (แจกฟรี), "วิธีลดเบี้ยวนัดโดยไม่ต้องใช้ระบบ" → ท้ายโพสต์ลิงก์ร้านเดโม
3. **ร้านเดโมที่ลองจองได้จริง** — ทุกคลิป/โพสต์พาไปที่ LINE ร้านเดโม "ลองจองดู 30 วิ" = เห็นของจริงก่อนคุย
4. **แนะนำเพื่อน** — ร้านแนะนำร้าน ได้ฟรี 1 เดือนทั้งคู่ (ช่างรู้จักช่าง และเชื่อช่างด้วยกัน — ตรงกับที่ลูกค้าจำลองบอก)
5. **พันธมิตร (เดือน 3+)** — ร้านขายอุปกรณ์ทำเล็บ/ผม, โรงเรียนสอนทำเล็บ: แบ่งค่าสมาชิกเดือนแรกต่อร้านที่แนะนำ

### ช่องทางขาย (Funnel) และเป้า
คนดูคลิป → แอด LINE OA ของเรา / ลองจองร้านเดโม → นัดคอลติดตั้ง → ทดลองฟรี → จ่ายเงิน

ตั้งเป้าเริ่มต้น (ปรับตามของจริงทุก 2 สัปดาห์): 10,000 วิว/เดือน → 100 แอด LINE (1%) → 25 นัดคอล (25%) → 15 ติดตั้ง → 9–10 จ่ายต่อ (60%)

### งบโฆษณา
เริ่มยิงโฆษณาเมื่อมีคลิปที่คนดูจบสูงโดยไม่ต้องจ่าย (organic) แล้ว → เอาคลิปนั้นไปยิง 2,000 บาท/เดือน วัด "ค่าได้ร้านทดลอง 1 ร้าน" ต้องต่ำกว่า ~400 บาท (= 2 เดือนของรายได้ร้าน)
